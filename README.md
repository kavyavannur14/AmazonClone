🚀 Amazon Homepage Clone

Just built an Amazon homepage clone! Super excited to share my latest project — a clean and responsive Amazon clone that replicates the original look of the e-commerce giant.

🔗 Live Demo

Click the link below to view the live website:

👉[ View Live Site Here :  ](https://amazon-clone-tdde.vercel.app/)

🔧 Tech Stack Used

✅ HTML5 - Semantic structure.

✅ CSS3 - Custom styling with Flexbox magic!

✅ Font Awesome - For scalable vector icons.

🧩 Features

📦 Category Dropdown: Custom dropdown for category selection (like the "All" menu).

🔍 Interactive Search: Search bar with a clickable search icon.

🎯 Flexbox Layout: Fully aligned and styled header using modern CSS Flexbox.

📱 Responsive Design: Adapts nicely to different screen sizes.
